# BRAYTON SRL — Sitio web oficial

Sitio corporativo de **BRAYTON SRL**, empresa de ingeniería, construcción y servicios integrales.

## Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Build para producción

```bash
npm run build
npm start
```

## Estructura principal

- **Home**: Hero, Nosotros, Servicios, Sectores, Proyectos destacados, Ventajas, Estadísticas, Testimonios, CTA
- **Nosotros**: Historia, misión, visión, valores
- **Servicios**: Construcción, ingeniería, arquitectura, instalaciones, transporte
- **Sectores**: Residencial, comercial, industrial, agro, factory, minería
- **Proyectos**: Galería con filtros y fichas por proyecto
- **Contacto**: Formulario, mapa, datos de contacto
- **Certificaciones**, **Clientes**, **Noticias/Blog**, **Trabaja con nosotros**
